# Plans

This repository has no `docs/plans/` directory and no plan files in the tree. Plans live in GitHub issues — on `zoolutions/pgmq-ruby` for fork-specific work, and on `mensfeld/pgmq-ruby` for anything that should land upstream, which is most of it. This directory exists so the lode's shape matches Lode Coding's and so `/lode:plan --file` has somewhere to write; nothing is duplicated here. Session handovers and gate evidence go in `../tmp/` and are not committed.
